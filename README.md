# AirTrail

Демо-фронтенд для визуализации рассеивания промышленных выбросов: карта с тепловыми шлейфами от труб, почасовой прогноз, контрольные точки и анимация ветра. Интерфейс на русском.

> Демонстрационный проект на мок-данных, а не нормативный расчёт рассеивания.

## Возможности

- тепловая карта шлейфа от двух источников, пересчитывается для выбранного часа и вещества;
- прогноз на 48 часов: перетаскиваемый таймлайн, стрелки, воспроизведение и возврат к «Сейчас»;
- семь веществ: PM2.5, PM10, NO₂, SO₂, CO, O₃ и AQI;
- слои: шлейф, контрольные точки, трубы и ветер;
- попапы с параметрами труб, выбросами и концентрациями;
- адаптивная вёрстка: на телефоне панель открывается поверх карты.

## Стек

React 18 · TypeScript · Vite · MapLibre GL JS 6 · Vitest + Testing Library

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + production-сборка в dist/
npm run preview
npm test
npm run lint
npm run format:check
```

Стиль карты по умолчанию — OpenFreeMap Liberty. Другой стиль задаётся переменной окружения:

```bash
VITE_MAP_STYLE_URL=https://tiles.openfreemap.org/styles/liberty
```

## Данные

Данные приходят из мок-бэкенда (`src/api/mockBackend.ts`) и проходят runtime-валидацию. Контракт ответа описан в `src/types.ts` (`ForecastResponse`) и `src/lib/validateForecast.ts`. Чтобы подключить реальный API, замените `fetchForecast()` на запрос к своему серверу.

## Ограничения

Шлейф — визуальная частичная симуляция с историей ветра, а не физически точный прогноз концентраций. Модель не учитывает рельеф, застройку, химические превращения и осаждение.
